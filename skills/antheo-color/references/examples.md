# Examples: what goes wrong, and the fix

Each pair is shown live, before and after, on the Antheo skills page. Without the skill, then with it:

| Without | With |
|---|---|
| Grey meta text at 3.1:1: too faint to read | Muted text at 7.7:1 (text needs at least 4.5:1) |
| Overdue shown only as a red date | “Overdue” said in words, with an icon |
| Brand purple on the title, the icon and every name | Colour only where it means something |

## When the default is wrong

A reference's artwork keeps its own palette in dark mode (a blue radio stays that blue); only the page around it adapts.
