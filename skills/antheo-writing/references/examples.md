# Examples: what goes wrong, and the fix

Each pair is shown live, before and after, on the Antheo skills page. Without the skill, then with it:

| Without | With |
|---|---|
| A title that names nothing: “Are you sure?”, “No data” | Name the thing: “Delete “Q4 plan”?”, “No invoices yet” |
| No consequence, or an error code | Say what happens, and what to do next |
| Buttons that say Yes, No or OK | Buttons that say what they do: “Delete plan”, “Try again” |
