# Examples: what goes wrong, and the fix

Each pair is shown live, before and after, on the Antheo skills page. Without the skill, then with it:

| Without | With |
|---|---|
| Hover looks exactly like rest: nothing answers the mouse | Hover darkens a step |
| Pressing it shows nothing | Press shrinks it to 97%, so you feel the click |
| No focus ring: someone on a keyboard can’t see where they are | A clear ring on focus |
| Loading swaps the words and the button changes width | A spinner inside; the button keeps its size |

## When the default is wrong

A toy-like control the person asked for (candy toggles, a big round action): pill shapes and large icons are part of the object, not a slip from the scale.
