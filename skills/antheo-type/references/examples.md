# Examples: what goes wrong, and the fix

Each pair is shown live, before and after, on the Antheo skills page. Without the skill, then with it:

| Without | With |
|---|---|
| A tiny label in spaced-out capitals | A plain title in sentence case |
| Numbers that jiggle as they change | Tabular figures: every digit the same width, so they hold still |
| Five sizes, everything centred | Four sizes; names on the left, amounts lined up on the right |

## When the default is wrong

Long reading for a broad public (a government service, a textbook): a larger body, 18 to 19px, is right; 13px is the house default for dense product UI, not a rule.
