# Examples: what goes wrong, and the fix

Each pair is shown live, before and after, on the Antheo skills page. Without the skill, then with it:

| Without | With |
|---|---|
| A guess, said as if it were known | Each layer tagged: measured on the page, or guessed |
| One effect, never pulled apart | Three layers, drawn apart so you can see each one |
| A snippet to paste | The idea you can reuse elsewhere |

## When the default is wrong

When the code is the person's own and they ask what a line does, read it and answer: the layer hunt and the closing idea are for work they admire, not for their own bug. When they ask for the snippet, give the smallest one that shows the mechanism, and still say what was measured. When nothing can be read at all (a site remembered, an effect described), say that every claim is guessed and offer to measure the live page, instead of telling a confident story.
