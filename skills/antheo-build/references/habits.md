# Habits to catch in yourself

Part of antheo-build. Read it before calling the work done, and check the build against each habit.

What agents do, in every write-up of agent-built UI (2025 to 26). None of them shows in a passing check.

- **"Done" on code evidence:** types, tests and a checker's score pass, and nobody opened the page. Open it, in
  light and dark, and press every control.
- **More than asked, or less than promised:** sorting, export and a sample dashboard nobody named; or a plan that
  said "inline editing" and shipped a read-only table. Build what the request names, and all of it.
- **Drift:** by the third screen there is a new grey, a fourth radius, a 14px padding. Re-read the block before
  each new screen.
- **Quieting a check instead of fixing it:** `overflow: hidden` over an overflow, `eslint-disable`, `as any`, a
  deleted test.
- **A fix loop:** after two failed tries at one bug, stop guessing and measure the live page (antheo-explain's
  `inspect.mjs`).
- **Another design skill pulling the other way** (extreme weights, layered gradients, staggered page-load reveals,
  a "distinctive" font). These rules win unless the person asked for that look.
