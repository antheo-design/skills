# Examples: what goes wrong, and the fix

Each pair is shown live, before and after, on the Antheo skills page. Without the skill, then with it:

| Without | With |
|---|---|
| Praise that says nothing: “super clean!” | What the screen is for, in one line |
| “Make it pop”: a feeling, not a fact | A fact you can see: both buttons are filled, so neither is the pick |
| Redesigns it without asking | Asks about the judgement calls and suggests one thing to try |

## When the default is wrong

The person asked for a verdict before release or said "just fix it": that is antheo-review or antheo-build, not seven points and three questions. An early sketch with no system yet is judged on its idea; skip the system check.
